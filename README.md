# 简单待办清单

当前版本：V17

这是一个简单的待办清单网页小工具。用户可以把要做的事情记录下来，完成后勾选，不需要时删除。

这个项目适合新手学习一个基础网页工具是怎样一步步做出来的：先做页面，再做功能，再优化使用体验。

## 这个项目是做什么的

这个项目仍然是“简单待办清单”。

用户可以在输入框里写下一件要做的事，然后点击“添加”按钮，或者按键盘 Enter，把它加入待办列表。每条待办事项都可以勾选为完成，也可以删除。

页面会把待办事项保存在浏览器里，所以刷新页面后，之前添加的内容和完成状态仍然会保留。

## 筛选功能说明

- 全部：显示所有任务
- 未完成：只显示未完成任务
- 已完成：只显示已完成任务

## 编辑功能说明

- 点击“编辑”进入编辑状态
- 可以修改任务文字
- 点击“保存”保存修改
- 点击“取消”放弃修改

## 创建时间功能说明

- 新增任务时会自动记录创建时间
- 每条任务会显示创建时间
- 刷新后创建时间仍然保留
- 编辑任务文字不会改变创建时间

## 截止日期功能说明

- 添加任务时可以选择截止日期
- 每条任务会显示截止日期
- 没有选择日期时，会显示“截止：未设置”
- 编辑任务时可以修改截止日期
- 刷新后截止日期仍然保留

## 日期管理功能说明

- 可以选择“原来的顺序”或“截止日期优先”
- 选择“截止日期优先”时，有截止日期的任务会按日期先后显示
- 没有截止日期的任务会排在后面
- 今天截止的未完成任务会显示“今天截止”
- 已经逾期的未完成任务会显示“已逾期”
- 页面会显示今天截止几件、已逾期几件

## 输入体验功能说明

- 空输入时会提示用户先输入任务
- 任务文字最多 60 字
- 输入框下方会显示当前字数
- 添加成功后会显示短提示
- 编辑保存成功后会显示短提示
- 浏览器保存失败时会显示兜底提示
- 点击“清除已完成”前会先确认，避免误删

## 批量操作功能说明

- 点击“全部完成”，可以把所有未完成任务设为完成
- 点击“全部取消完成”，可以把已完成任务恢复为未完成
- “清除已完成”仍然可以一次删除所有已完成任务
- 页面会显示总任务数、已完成数和未完成数
- 没有任何任务时，批量操作按钮会自动不可用
- 批量操作完成后会显示短提示

## 搜索功能说明

- 可以在搜索框里输入关键词查找待办事项
- 搜索会按任务文字和备注匹配
- 搜索可以和“全部 / 未完成 / 已完成”筛选一起使用
- 搜索可以和排序方式一起使用
- 搜索时会显示找到几条结果
- 点击“清空搜索”可以恢复正常列表
- 搜索不到结果时，会显示清楚提示

## 优先级功能说明

- 添加任务时可以选择低、中、高优先级
- 每条任务会显示优先级标记
- 不同优先级会用不同颜色区分
- 编辑任务时可以修改优先级
- 排序方式里可以选择“优先级优先”

## 备注功能说明

- 添加任务时可以填写备注
- 每条任务可以显示备注
- 没有备注时不会显示空备注区域
- 编辑任务时可以修改备注
- 搜索关键词也可以匹配备注内容

## 标签功能说明

- 添加任务时可以填写标签，比如“学习”“工作”“生活”
- 每条任务会显示标签
- 编辑任务时可以修改标签
- 搜索关键词也可以匹配标签内容
- 可以用“标签筛选”只查看某一个标签下的任务
- 标签选项会根据已有任务自动生成

## 快速日期功能说明

- 点击“今天”，可以把添加区的截止日期设为今天
- 点击“明天”，可以把添加区的截止日期设为明天
- 点击“清除日期”，可以清空添加区的截止日期
- 仍然可以手动选择任意截止日期

## 数据管理功能说明

- 页面会显示浏览器当前保存了多少条任务
- 点击“清空全部”，可以删除所有任务
- 清空全部前会出现两次确认，避免误删
- 清空全部后，标签筛选会自动回到“全部标签”

## 数据安全和备份说明

- 删除任务后，会出现“可撤销”的提示
- 点击“撤销”，可以恢复刚刚删除的任务
- 清除已完成和清空全部后，也可以撤销
- 点击“导出备份”，可以把当前任务保存成 JSON 文件
- 点击“导入备份”，可以选择以前导出的 JSON 文件
- 导入备份会替换当前列表，所以会先确认
- 点击“恢复示例数据”，可以重新生成三条示例任务
- 恢复示例数据会替换当前列表，所以会先确认

- 统计、批量操作、筛选、搜索、标签筛选、排序、数据管理和备份入口放在管理区域

## V14 项目结构说明

V14 开始，这个项目不再把所有内容都放在 `index.html` 里，而是拆成三个主要文件：

- `index.html`：负责页面结构，也就是页面上有什么。
- `style.css`：负责页面样式，也就是页面长什么样。
- `script.js`：负责页面功能，也就是按钮点击后发生什么。

这样拆分以后，后面继续开发会更清楚：

- 想改文字和页面区域，主要看 `index.html`
- 想改颜色、间距、按钮样式，主要看 `style.css`
- 想改添加、删除、筛选、搜索、备份等功能，主要看 `script.js`

## V15 代码整理说明

V15 没有主要改变页面外观，也没有新增业务功能。

这一版重点整理了 `script.js`：

- 增加代码分区，让文件更容易从上往下读

- 把快速日期逻辑整理成 `setQuickDueDate()`
- 给 `renderTodos()` 等关键区域增加新手注释

简单理解：

```text
V14 是拆文件
V15 是整理功能代码
```

## V16 渲染拆分说明

V16 继续整理 `script.js`。

这一版重点整理 `renderTodos()`。

以前 `renderTodos()` 同时负责很多事情：

- 更新统计数字
- 判断哪些任务应该显示
- 显示空列表提示
- 画编辑状态的任务
- 画普通状态的任务

V16 把这些事情拆成了更小的函数：

- `getTodoStats()`：计算统计数字
- `updateStats()`：更新统计区域
- `getVisibleTodos()`：计算当前应该显示哪些任务
- `updateEmptyMessage()`：更新空列表提示
- `renderEditTodo()`：画编辑状态任务
- `renderNormalTodo()`：画普通状态任务
- `renderTodoItem()`：决定画哪一种任务

简单理解：

```text
V15 是整理功能代码
V16 是继续拆小 renderTodos()
```
